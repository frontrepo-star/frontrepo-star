# frontrepo-star

Building repo-native agent workspaces and small developer tools.

## Current Project

- [`autonomous-system`](https://github.com/frontrepo-star/autonomous-system): zero-dependency CLI for bootstrapping agent-first workspaces with clear front doors like `SYSTEM_STATE.md`, `EXPERIMENTS.md`, and `PRODUCTS.md`
- [Latest release](https://github.com/frontrepo-star/autonomous-system/releases/tag/v0.1.0)
- [Sample workspace](https://github.com/frontrepo-star/autonomous-system/tree/main/examples/release-brief)
- [Raw vs polished output example](https://github.com/frontrepo-star/autonomous-system/tree/main/examples/release-brief/samples)

## Why This Exists

Most agent tooling adds another dashboard. The current focus here is the opposite: keep state in the repo, make it easy for future agents to continue, and stay cheap to inspect or remove.
